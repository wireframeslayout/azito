# ワークスペースガイド

ワークスペースは AZITO の中心的な画面で、プロジェクトに紐づくすべてのリソースを統合的に管理します。

## レイアウト

ワークスペースは以下の4つのエリアで構成されます。

```
+----------+----+------------------+---------------------------+
| Project  | AB |    Sidebar       |        Main Area          |
|  Bar     |    |                  |                           |
|          |    |  (Windows,       |  (Terminal, File,         |
| (left)   |    |   Tasks, etc.)   |   Task, Unit,             |
|          |    |                  |   Sidekick, Issue tabs)   |
|          |    |                  |                           |
+----------+----+------------------+---------------------------+
```

Sidekick（タグ付きスキルパッケージ）・Unit（オペレーションを実行するチーム）・Operation（Unit の実行ラン）は
プロジェクトに紐づく実行環境ではなく、全プロジェクト共通のグローバルなリソースです。プロジェクト単位の
サイドバーには含まれず、上部ナビゲーションの **Units** / **Sidekicks** / **Operations**
からメインエリアのタブとして開きます。

- **プロジェクトバー（左端）** -- 登録されたプロジェクトの一覧。クリックでプロジェクトを切り替え
- **アクティビティバー（AB）** -- サイドバーのモードを切り替えるアイコンバー
- **サイドバー** -- 選択中のモードに応じたコンテンツを表示
- **メインエリア** -- タブで管理されるコンテンツ表示領域

## サイドバーモード

アクティビティバーのアイコンをクリックして、サイドバーの表示モードを切り替えます。

### Windows

プロジェクトに登録された tmux ウィンドウとそのペインの一覧を表示します。ペインをクリックすると、メインエリアにターミナルタブが開きます。

- 「+」ボタンで既存の tmux ウィンドウの追加、または新規ウィンドウの作成が可能
- 「+」ボタンから「Entire Session」タブでセッション内の全ウィンドウを一括登録可能
- 新規ウィンドウ作成時にはコーディングエージェント（Claude Code / Codex）の自動起動を設定可能
- ウィンドウを右クリックで「Detach（プロジェクトから外す）」「Delete（tmux ウィンドウを終了）」を選択可能。「プロジェクトに追加」サブメニューから、他のプロジェクトへウィンドウを追加することも可能（追加済みのプロジェクトは選択済み表示になる）
- ウィンドウの Remove 時に、そのウィンドウのペインに紐づく開いているタブを自動的に閉じる
- エージェントが稼働中のウィンドウには、円形スピナーに代わりネオンシマー（グラデーション光沢）と braille スピナーを表示
- サイドバーの幅は全プロジェクトで共通（同期）

### Tasks

プロジェクトのタスク一覧を表示します。各タスクは Unit（ワークフロー定義＋実行ランタイム）に紐づいて実行されます。

- タスクのステータス（open / in_progress / planning / implementing / reviewing 等）をリアルタイム表示
- クリックでタスクの詳細パネル（実行ログ、フェーズ進捗バー）を表示
- 「+」ボタンでタスクの新規作成。GitHub/GitLab イシューからのインポートにも対応
- タスク実行（Execute）、停止（Stop）がメインエリアから操作可能

### Files

プロジェクトのサーバー上のファイルツリーを表示します。

- ディレクトリの展開・折りたたみ
- ファイルをクリックするとシンタックスハイライト付きのプレビューをメインエリアに表示
- highlight.js による多言語対応のコードハイライト
- 画像ファイル（PNG, JPEG, GIF, WebP, SVG, BMP, ICO, TIFF）のインラインプレビュー
- PDF ファイルのプレビュー表示に対応
- ダウンロードボタンでサーバー上のファイルをブラウザにダウンロード（50MB 制限）
- 「Open in VS Code」「Open in Zed」ボタンで外部エディタからファイルやフォルダを直接オープン（Tailscale ホスト名自動検出対応）

詳細は [ファイル操作ガイド](./files.md) を参照してください。

### Repositories

プロジェクトに紐づけたリポジトリの一覧を表示します。

- リポジトリを選択するとイシュー一覧がメインエリアに表示
- Issues / Pull Requests タブの切り替えに対応
- イシューの検索、ステータスフィルター（open / closed / all）に対応
- イシュー詳細の表示、イシューからタスクへのインポートが可能
- プルリクエスト / マージリクエストのステータスバッジ付き一覧表示（Open / Merged / Closed / Draft）
- GitHub / GitLab の両方に対応

詳細は [GitHub/GitLab 連携ガイド](./github-integration.md) を参照してください。

### Storage

プロジェクトのファイルストレージ（MinIO）を管理します。

- ファイルのアップロード（ボタンまたはドラッグ&ドロップ）
- ファイル一覧の表示（サムネイル付き）
- ファイル URL のコピー、ファイルの削除
- ダウンロードボタンでファイルをブラウザにダウンロード

詳細は [ファイルストレージガイド](./storage.md) を参照してください。

### Settings

プロジェクトの設定を編集します。

- プロジェクト名、説明、リポジトリ URL、デフォルトブランチ
- アイコン（絵文字または画像アップロード、クロップ付き）とテーマカラーの設定
- デフォルト Unit の選択
- Sidekick プロンプトの設定
- サーバー・ウィンドウ・リポジトリの管理
- Secrets の管理（`AZITO_SECRET_*` 環境変数としてタスク実行時に注入される秘密情報）
- プロジェクトの削除

## プロジェクト切り替え

画面左端のプロジェクトバーに、登録されたプロジェクトのアイコン（設定済みの場合は絵文字、未設定の場合は頭文字）がテーマカラー付きで表示されます。クリックすると即座にワークスペースが切り替わります。

また、サイドバーのタイトル部分（プロジェクト名）をタップすると、ドロップダウンメニューが表示され、アイコンとカラー付きのプロジェクト一覧からすばやく切り替えられます。この操作はデスクトップ・モバイルの両方で利用可能です。

## サイドバーの操作

### 折りたたみ

アクティビティバーの最上部にあるトグルボタンでサイドバーの表示・非表示を切り替えられます。折りたたみ状態はプロジェクトごとに保存されます。

### リサイズ

サイドバーとメインエリアの境界をドラッグして幅を調整できます（200px 〜 600px）。ダブルクリックでデフォルト幅（320px）にリセットされます。リサイズ幅は全プロジェクトで共通の値として保存されます。

## タブ管理

メインエリアの上部にタブバーがあり、開いているコンテンツを管理します。

### タブの種類

- **ターミナルタブ** -- tmux ペインへの接続（xterm.js）。非アクティブなタブの接続は切断され、再アクティブ化時に自動再接続される（メモリ節約）
- **ファイルタブ** -- ファイルのプレビュー表示
- **タスクタブ** -- タスクの詳細パネル（実行ログ、フェーズ進捗バー）
- **Unit タブ** -- Unit（ワークフロー定義＋実行ランタイム）の詳細・編集パネル
- **Sidekick タブ** -- Sidekick（タグ付きスキルパッケージ）の詳細・編集パネル
- **イシュータブ** -- GitHub/GitLab イシューの詳細

### Active Windows

サイドバー下部に常駐するセクションで、エージェントが稼働中のウィンドウをリアルタイムで一覧表示します。

> 旧 PiP（Picture-in-Picture）フローティングモニタと入力モード（Input タブ）は v0.2.1 で廃止されました。稼働監視は Active Windows が担います。

- 稼働中の行にネオンシマー（ピンク→紫→青のグラデーション光沢）と braille スピナーを表示
- ブロック中（承認待ち）の行にはオレンジの波紋アニメーションを表示し、「承認待ち」ラベルを付与
- 処理完了後も「未確認の完了」としてエントリを一覧に保持（緑チェック＋経過時間表示）。行をタップして表示すると一覧から消える
- タスクに紐づくウィンドウは、行をタップするとタスク詳細タブ内で当該ターミナルを表示する（タスクに紐づかないウィンドウは通常のターミナルタブを開く）
- 行をタップすると、そのウィンドウが属するプロジェクトへワークスペースのフォーカスも移動する
- 注視判定はペイン単位（実際に表示中のペインのみ watched 扱い）。複数ウィンドウを持つタスクでも、非表示側の承認待ち・完了が正しく一覧に表示される
- 稼働状態インジケーター（working / blocked / finished）は Windows サイドバーやタスクのウィンドウ一覧・ドロップダウンにも表示される
- window 名をラベルの2行目に dim テキストで表示
- 件数が 0 の間は自動的にヘッダー行のみに最小化され（トグル操作も無効）、1 件以上に転じると自動的に展開する
- 展開/最小化のトグル状態、および「未確認の完了」エントリは localStorage に永続化され、リロード後も復元される
- SP（768px 以下）ではフローティングメニューバーの Active Windows ボタン（件数バッジ付き）からガラスパネルの一覧を開く

### 操作

- **切り替え** -- タブをクリック
- **閉じる** -- タブの「x」ボタンをクリック
- **スクロール** -- タブが多い場合、マウスホイールで左右スクロール
- **並び替え** -- タブをドラッグ&ドロップで順序変更
- **ドロップダウンメニュー** -- 「▾」ボタンから全タブ一覧を表示
- **自動スクロール** -- タブ選択時、アクティブタブが可視領域に自動スクロール
- **稼働中インジケーター** -- エージェントが稼働中のタブは下端にネオンコメット（ピンク→紫→青のグラデーション）アニメーションと braille スピナーを表示（`prefers-reduced-motion` 設定時は静的表示にフォールバック）

### タブのプロジェクト横断化

タブはプロジェクトを切り替えても維持されます。

### タブの永続化

タブの状態（開いているタブ、アクティブタブ）は localStorage に保存され、ページをリロードしても復元されます。保存はプロジェクトごとに管理されます。

## テーマとアピアランス

Settings > Appearance から、ターミナルと画面全体の見た目をカスタマイズできます（保存ボタンなしのライブ編集・即時反映）。

- **プリセットテーマ 7 種** -- Azito Aurora（デフォルト、ピンク→青グラデーション）/ GitHub Dark / Dracula / Nord / Solarized Dark / Monokai / One Dark
- **カラーカスタマイズ** -- 背景・文字・カーソル・選択色・ANSI 16 色を個別に編集。編集するとプリセットからカスタム扱いに切り替わる
- **自作テーマ** -- カスタマイズした配色＋背景設定に名前を付けて保存・選択・上書き保存・削除が可能
- **背景カスタマイズ** -- グラデーション 4 パターン（オーロラ / リニア / グロー / メッシュ）、画像（URL または IndexedDB 保存）、単色から選択。画像にはオーバーレイエフェクト 6 種（darken / color / blur / gradient / vignette / none）を適用可能
- **適用範囲** -- 「ターミナルのみ」と「画面全体」を切り替え。画面全体ではサイドバー・タブバー・フォーム等のワークスペース面が半透過＋ブラーになり背景が透ける（浮遊 UI は不透明のまま）
- **UI ボーダー色** -- テーマごとに UI の境界線色を設定可能
- **プロジェクト連動** -- プロジェクトごとにテーマを指定でき、タブ切替で自動適用
- 設定は localStorage（`azito-terminal-theme`）に永続化（背景画像は IndexedDB）。xterm.js には WebSocket を切断せず動的に適用される

## ページナビゲーション

一覧・フォーム・詳細画面には統一的なレイアウトシェルが適用されています。

- **PageContainer** -- 最大幅 1400px の中央寄せコンテナ。すべてのページ本文を包む共通の余白・スクロール制御を提供
- **PageHeader / PageBody** -- ページ上部の見出し・アクション領域（PageHeader）と本文領域（PageBody）を分離するレイアウトパーツ
- **EyebrowBack** -- 詳細・フォーム画面のタイトル上部に表示される「← 一覧に戻る」リンク。タブの opener（そのタブを開いた元のタブ）関係を辿って一覧タブに戻る導線を提供する
- **Unit 詳細ページ** -- 「Now Running（実行中の Operation 一覧）」「Behavior（フェーズ設定などの振る舞い定義）」「Tasks（この Unit で実行されたタスク一覧）」の3セクション構成に再設計

## URL ベースのナビゲーション

ワークスペースの URL はサイドバーモードを含みます。

```
/workspace/:projectId/:mode
```

例:
- `/workspace/1/windows` -- プロジェクト 1 のウィンドウ一覧
- `/workspace/1/tasks` -- プロジェクト 1 のタスク一覧
- `/workspace/1/repos` -- プロジェクト 1 のリポジトリ一覧
- `/workspace/1/storage` -- プロジェクト 1 のストレージ
- `/workspace/1/settings` -- プロジェクト 1 の設定

URL を直接共有することで、特定のプロジェクト・モードに直接アクセスできます。

## モバイル対応

AZITO はモバイルブラウザからの利用にも対応しています。

- **フローティングメニューバー（MobileMenuBar）** -- 画面下部に常駐するフローティングメニュー。左グループ（プロジェクト切替 / タスク一覧 / ファイル / その他）と右グループ（キーボードコントロール / 通知 / 設定）の2グループで構成される。ソフトキーボード表示中は自動的にスライドダウンして退場する
- **モバイルサイドバー** -- デスクトップ版と同じアクティビティバー + サイドバー構成。タップ操作に最適化されたサイズ・余白で表示
- **プロジェクト切り替え** -- フローティングメニューバーのプロジェクトアイコンをタップするとプロジェクト切り替えポップオーバーが表示されます。アイコンとカラーで各プロジェクトを識別可能
- **SP キーボードコントロールオーバーレイ** -- フローティングメニューバーのキーボードアイコンから開くオーバーレイ。ドラッグで位置を移動可能・40% 透過表示で、フォーカスを奪わずに表示中のウィンドウへコマンド（矢印キー・Ctrl+C 等）を送信できる
- **通知メニュー** -- 全画面オーバーレイで通知センターを表示
- **Active Windows パネル** -- フローティングメニューバーの Active Windows ボタン（稼働件数バッジ付き）からガラスパネルの稼働ウィンドウ一覧を表示
- **PWA ホーム画面追加** -- ブラウザの「ホーム画面に追加」でネイティブアプリのように利用可能（HTTPS 環境が必要）
- **タッチスワイプスクロール** -- ターミナル画面でタッチスワイプによるスクロールが可能。慣性スクロール対応
- **クイックアクションボタン** -- モバイル表示時（768px 以下）、ターミナル上部に Enter / Tab / Esc / Ctrl+C / ↑ / ↓ のボタンを表示
- **ロングプレスメニュー** -- サイドバーのサーバー・セッション・ウィンドウ・ペイン行やタブを長押しすると、右クリックと同等のコンテキストメニューが表示
- **カンバンタイトル複数行表示** -- モバイルでのカンバンボードでタスクタイトルが2行で折り返し表示（単行省略から改善）
