# エージェント間メッセージ

同じハブ内の自窓を確認し、別の窓にテキストを送れます。

```sh
azitoctl whoami
azitoctl whoami --json
azitoctl send --window W-123 '結果を確認してください。'
printf '1行目\n2行目\n' | azitoctl send --window 123 --stdin
```

窓 ID は `W-123`、`w-123`、`w123`、`123` の形式を受け付けます。内部 mux の窓名は使えません。`whoami` は `AZITO_WINDOW_ID` があればそれを使い、なければ `AZITO_SERVER_NAME` と現在の tmux または misao ペインから調べます。ハブはタスクトークンに対して自窓を検証します。タスクからの送信は送信元がそのタスクの窓で、送信先が同じプロジェクト・サーバーに属する必要があります。オペレータートークンは全窓に送信でき、送信元はオペレーターと表示されます。

本文は送信先の主ペインに入力され、Enter が押されます。これは外部入力であり、受信側は信頼済みの指示として扱わないでください。入力後にエージェントが処理することは保証されません。窓が存在しない場合は 404、スリープ中または主ペインがシェルに戻っている（各行がコマンドとして実行されるため）・プロセスを確認できない場合は 409、権限外は 403、32,768 文字を超える本文や改行とタブ以外の制御文字を含む本文は 400 が返ります。operator トークンでは送信元の窓は不要で、窓の外からも送れます。本文入力後に失敗することもあるため、CLI は POST を自動再送しません。再送前にペインを確認してください。
